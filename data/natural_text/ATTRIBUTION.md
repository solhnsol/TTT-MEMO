# Attribution and licence

The texts in these world files are derived from English Wikipedia (dump 2023-11-01, via the `wikimedia/wikipedia`
dataset), licensed CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/). Changes: paragraphs were selected and
split, person names were replaced by invented names, and some sentences were deleted. The derived files are shared
under the same licence.

Fact triples come from PopQA (Mallen et al., 2023; `akariasai/PopQA`) and T-REx (Elsahar et al., 2018;
`relbert/t_rex`). Check both licences against their original sources before any public release.

No file in this directory contains a real person's name, Wikipedia title or Wikidata id. The mapping to the real
people is kept outside the repository and must not be committed.
